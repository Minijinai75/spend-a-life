# 活到老，花到老

> 不是算一生要花多少錢，是算**一生有多少時間是自己的**。
> BUILDMODE GEN-AI HACKATHON 2026｜隊伍 T058 同簷｜賽道 02 AI for Everyday Life

## 問題與目標

每個人都在焦慮錢，但幾乎沒有人真的算過自己這輩子要花多少、要工作多久才夠。焦慮沒有形狀，所以只能一直焦慮。這個工具要讓人**看見**一件事：為了生活，現在的生活到底夠不夠？有沒有留時間給自己？

遊戲分三幕，一幕回答一個問題：

1. **我這輩子要花多少錢**——選住哪、吃什麼、寵物、爸媽、小孩，算出一個總數（老師的原題）。
2. **這些錢要用多少時間去換**——填自己的薪水，擲骰走到八十歲，機會與命運打斷你。
3. **剩下的時間怎麼規劃**——終點翻面：「這輩子要花 3,600 萬」變成「一生 68% 是自己的、一天剩 9.3 小時」；退回任何一年重選，拉存款、保險、薪水看人生怎麼變；最後把整局帶去跟自己的 AI 討論。

時間只在玩完以後出現——前半段只有錢，走到終點那一秒才翻成時間，那一下才夠重。

目標使用者是每一個對錢有焦慮的台灣人，尤其是剛出社會、在想要不要換工作、要不要買房的人。

緣起：作者上課時老師讓大家算「一生要花多少錢」，算完嚇到。這個「嚇到」就是遊戲要給玩家的那一下。

## 核心功能

- **角色創建**：性別、年齡、你的薪水（每五年一格可改，不知道填多少可用職業中位數）、住哪（六都或住家裡）——租金走實價登錄中位數。
- **蛇形棋盤**：每格一年，擲骰前進；機會疊（加薪、爸媽給頭期、中樂透、老家都更）與命運疊（生病、裁員、父母長照、房東漲租）打斷人生；里程碑格停下來做選擇（買房、結婚、生小孩、退休）。
- **前半段只講錢**：加減表算出每月與一輩子要花多少；棋盤上只看存款與今年花費；花得比賺得多會被標出來。
- **終局翻面**：總花費變成「一生幾成是自己的、一天剩幾小時」，24 小時分段條、人生曲線、需要的薪水線；「調整人生」板拉存款、保險、薪水同一顆骰子重跑；退回任何一年重選看差多少。
- **終局三樣帶走**：分享卡、人生一頁、**一段給 AI 的 prompt**（自動帶入整局數據與選擇，一鍵複製，貼到自己的 ChatGPT／Claude 接著聊）。

## 系統架構

單頁 HTML＋CSS＋原生 JavaScript，零框架、零後端、零 API 也能完整玩。

```
使用者瀏覽器（手機直式優先）
└── game/index.html
    ├── UI 五幕（角色創建 → 棋盤 → 事件卡 → 終局）
    ├── simulateLife()  純函式：每年結算收入／支出／自由時間
    └── data/*.json     台灣公開統計快照（fetch 失敗時用內嵌快照）
外部（可選）
├── Twinkle Hub MCP → 內政部實價登錄（六都租金／房價中位數，即時層）
└── Gemini 3.8 Flash（有 key 才開）：開局對話生成專屬牌組、每格一句家人口氣
```

架構圖：見 `docs/architecture.html`（HTML＋CSS 繪製）。

## 安裝與執行

```bash
git clone https://github.com/Minijinai75/spend-a-life.git
cd spend-a-life
# 方法一：直接用瀏覽器開 game/index.html（file:// 也能玩，走內嵌數據快照）
# 方法二：起一個靜態伺服器，讀 data/*.json
python -m http.server 8000
# 開 http://localhost:8000/game/
```

不需要任何 API key。想開 AI 加料，複製 `config.example.js` 為 `config.js` 填入自己的 Gemini key（`config.js` 已在 .gitignore）。

## 限制與未來工作

- 支出模型是全國／五都平均，桃園與台南主計處未單列，用實價登錄補「住」的成本；其餘項目用全國平均。
- 薪資成長曲線與稅後係數是簡化假設（在程式中標示 `PLACEHOLDER_MODEL`），非官方數字。
- 自由工作者薪資官方無中位數，用推估並在畫面上標示。
- 事件卡機率為設計值，不是統計機率。
- 未來：接更多即時開放資料（Twinkle Hub）、加入通膨與利率情境、把「給 AI 的 prompt」做成可直接開對話的深連結。
